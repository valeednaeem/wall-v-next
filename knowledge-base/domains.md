## Domain Transfer

### Transfer Process
1. Unlock domain at current registrar
2. Obtain EPP/authorization code
3. Initiate transfer through control panel
4. Confirm transfer via email
5. Transfer completion (typically 5-7 days)

### Transfer Requirements
- Domain must be at least 60 days old
- Domain must not be in locked status
- Valid authorization code required
- Admin contact email must be accessible
- No pending disputes or legal holds

### Transfer Pricing
- Transfer fees: $9.99 for most TLDs
- Includes 1 year extension upon successful transfer
- No additional transfer fees from us
- Bulk transfer discounts available

### Transfer Restrictions
- .uk domains: Nominet transfer process
- .au domains: DACS process
- .ca domains: CIRA transfer process
- Some ccTLDs have specific transfer rules

## WHOIS Privacy Protection

### What is WHOIS Privacy?
- Hides personal information from public WHOIS records
- Replaces your details with proxy information
- Prevents spam and unwanted contact
- Maintains compliance with ICANN requirements

### Privacy Protection Features
- Free with all domain registrations
- Proxy email and phone number
- Mail forwarding for legitimate inquiries
- Legal compliance maintained
- Easy opt-out if required

### Information Protected
- Registrant name and organization
- Physical address
- Email address
- Phone number
- Administrative and technical contacts

## Auto-Renewal

### Auto-Renewal Benefits
- Prevents accidental domain expiration

## Domain Statuses

### Status Definitions

| Status | Description |
|--------|-------------|
| Active | Domain is registered and functioning normally |
| Pending Registration | Registration request is being processed |
| Pending Transfer | Domain transfer is in progress |
| Expired | Registration period has ended, in grace period |
| Suspended | Domain suspended due to policy violation or payment issue |
| Transferring | Domain is being transferred to another registrar |
| Redemption | Domain in redemption period after expiration |
| Locked | Domain locked to prevent transfers or changes |

### Status Management
- View current status in dashboard
- Request status changes
- Understand status implications
- Restore suspended domains
- Cancel pending transfers

### Expiration Timeline
- **Active**: Domain is fully functional
- **Grace Period** (30 days): Domain expires but can be renewed at standard rate
- **Redemption** (30 days): Domain can be restored with additional fee
- **Pending Delete** (5 days): Domain queued for permanent deletion
- **Released**: Domain becomes available for new registration

## Domain Expiration and Recovery

### Expiration Process
1. **Active period**: Domain functions normally
2. **Grace period** (30 days): Renewal available at standard rate
3. **Redemption period** (30 days): Restoration with additional fee
4. **Pending delete** (5 days): Domain queued for release
5. **Released**: Domain available for new registration

### Recovery Options
- **Grace period renewal**: Standard renewal fee
- **Redemption restoration**: Additional $80 fee plus renewal
- **Post-deletion recovery**: Not possible
- **Backorder service**: Available for premium domains

### Expiration Prevention
- Auto-renewal enabled by default
- Multiple reminder emails
- SMS notifications
- Dashboard alerts
- Emergency contact notifications
