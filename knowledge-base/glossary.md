# Wall-V Platform Glossary

## AI Terms

| Term | Definition |
|------|------------|
| LLM | Large Language Model. A neural network trained on vast text data capable of generating and understanding human language. Used in Wall-V chat and voice agents. |
| RAG | Retrieval-Augmented Generation. A technique that combines LLM generation with retrieval from external knowledge bases to produce more accurate, grounded responses. |
| NLP | Natural Language Processing. A branch of AI focused on enabling computers to understand, interpret, and generate human language. |
| Fine-tuning | The process of further training a pre-trained model on domain-specific data to improve performance for particular tasks. |
| Embeddings | Numerical vector representations of text that capture semantic meaning, used for similarity search and clustering in AI applications. |
| Vector DB | Vector Database. A database optimized for storing and querying high-dimensional vectors, used in RAG pipelines for semantic search. |
| Prompt Engineering | The practice of designing and refining input prompts to elicit desired outputs from AI models. |

## Business Terms

| Term | Definition |
|------|------------|
| CRM | Customer Relationship Management. Software for managing interactions with current and potential customers, tracking leads, and sales pipelines. |
| ERP | Enterprise Resource Planning. Integrated management software that handles core business processes including finance, HR, manufacturing, and supply chain. |
| SaaS | Software as a Service. A cloud-based software delivery model where applications are hosted and provided over the internet on a subscription basis. |
| B2B | Business to Business. Commercial transactions and relationships between two businesses rather than between a business and individual consumers. |
| B2C | Business to Consumer. Commercial transactions directly between a business and individual end consumers. |
| MVP | Minimum Viable Product. A product with just enough features to satisfy early users and gather feedback for future development. |
| ROI | Return on Investment. A performance metric measuring the gain or loss generated relative to the investment cost. |
| KPI | Key Performance Indicator. A measurable value that demonstrates how effectively a business is achieving key objectives. |

## Technical Terms

| Term | Definition |
|------|------------|
| API | Application Programming Interface. A set of rules and protocols that allows different software applications to communicate with each other. |
| REST | Representational State Transfer. An architectural style for designing networked applications, using standard HTTP methods for communication. |
| GraphQL | A query language and runtime for APIs that allows clients to request exactly the data they need in a single request. |
| Webhook | A user-defined HTTP callback triggered by an event in a source application, sending data to a specified URL in real time. |
| Middleware | Software that acts as a bridge between an operating system or database and applications, especially on a network. In Next.js, functions that run before a request is completed. |
| SSR | Server-Side Rendering. A technique where pages are rendered on the server and sent as fully formed HTML to the client browser. |
| CSR | Client-Side Rendering. A technique where pages are rendered in the browser using JavaScript after the initial HTML is loaded. |
| SPA | Single Page Application. A web application that loads a single HTML page and dynamically updates content without full page reloads. |

## Hosting Terms

| Term | Definition |
|------|------------|
| VPS | Virtual Private Server. A virtualized server environment that provides dedicated resources within a shared physical server. |
| CDN | Content Delivery Network. A distributed network of servers that delivers cached content to users based on geographic proximity. |
| SSL | Secure Sockets Layer. A cryptographic protocol that encrypts data transmitted between a web server and browser, indicated by HTTPS. |
| DNS | Domain Name System. The hierarchical naming system that translates human-readable domain names into IP addresses. |
| cPanel | A web-based hosting control panel providing graphical interface and automation tools for managing web hosting accounts. |
| WHM | Web Host Manager. A server administration tool used by hosting providers to manage accounts, packages, and server settings. |
| Uptime | The amount of time a server or system is operational and available, typically expressed as a percentage. Wall-V guarantees 99.9% uptime. |
| Bandwidth | The maximum rate of data transfer across a network path, measured in bits per second or bytes per second. |

## Payment Terms

| Term | Definition |
|------|------------|
| IPN | Instant Payment Notification. A message sent by a payment processor to notify a merchant of a transaction event such as payment received or refunded. |
| HMAC | Hash-based Message Authentication Code. A cryptographic technique used to verify the integrity and authenticity of a message, commonly used for webhook signature verification. |
| Buy Link | A pre-generated URL that directs a customer to a payment page for a specific product or service with amount and details pre-filled. |
| Checkout | The process where a customer completes a purchase by providing payment and billing information. |
| Invoice | A document issued by a seller to a buyer detailing the products, services, quantities, agreed prices, and payment terms. |
| Quote | A formal estimate of the cost for specific products or services, typically valid for a defined period. |
| Milestone | A significant checkpoint in a project that marks the completion of a deliverable, often tied to a partial payment. |

## Project Terms

| Term | Definition |
|------|------------|
| Discovery | The initial phase of a project focused on understanding requirements, goals, constraints, and stakeholder expectations. |
| Milestone | A defined point in a project timeline marking the completion of a major deliverable or phase. |
| Sprint | A fixed time period (typically 1-4 weeks) during which a specific set of work items must be completed in agile development. |
| Backlog | An ordered list of features, tasks, and fixes to be addressed in a project, maintained and prioritized by the product owner. |
| Standup | A brief daily meeting where team members share what they accomplished, what they are working on, and any blockers they face. |
| Retrospective | A meeting held at the end of a sprint or project phase to reflect on what went well, what did not, and what to improve. |

## Legal Terms

| Term | Definition |
|------|------------|
| GDPR | General Data Protection Regulation. European Union regulation governing data protection and privacy for individuals within the EU and EEA. |
| CCPA | California Consumer Privacy Act. A California state statute that enhances privacy rights and consumer protection for residents of California. |
| DPA | Data Processing Agreement. A legally binding contract between a data controller and a data processor specifying obligations for handling personal data. |
| TOC | Terms and Conditions. The legal agreement between a service provider and a user governing the use of a service or website. |
| SLA | Service Level Agreement. A commitment between a provider and client defining the level of service expected, including uptime, response time, and resolution time. |
| NDA | Non-Disclosure Agreement. A legal contract establishing a confidential relationship between parties to protect proprietary information. |
| DMCA | Digital Millennium Copyright Act. United States copyright law that implements international treaties to protect digital content from unauthorized use. |

## Marketing Terms

| Term | Definition |
|------|------------|
| SEO | Search Engine Optimization. The practice of optimizing website content and structure to improve visibility and ranking in organic search engine results. |
| SEM | Search Engine Marketing. A digital marketing strategy that increases website visibility in search engine results pages through paid advertising. |
| PPC | Pay Per Click. An advertising model where advertisers pay a fee each time their ad is clicked, commonly used in search and display advertising. |
| CTR | Click-Through Rate. The percentage of people who click on a link or advertisement out of the total who view it. |
| CPA | Cost Per Action. An advertising pricing model where advertisers pay only when a specific action (signup, purchase, download) is completed. |
| CAC | Customer Acquisition Cost. The total cost of acquiring a new customer, including marketing and sales expenses divided by the number of new customers. |
| LTV | Lifetime Value. The total revenue a business can expect to generate from a single customer throughout their entire relationship. |
| Churn | The rate at which customers stop doing business with a company, expressed as a percentage of total customers over a given period. |
