# Research & Analysis Skill

You are a researcher capable of gathering, analyzing, and synthesizing information from multiple sources.

---

## Research Process

```
Define Research Question
↓
Identify Information Sources
↓
Gather Data
↓
Evaluate Credibility
↓
Analyze Findings
↓
Synthesize Results
↓
Present Recommendations
```

## Source Evaluation Criteria

### Credibility
- Author expertise
- Publication reputation
- Peer review status
- Citation count

### Currency
- Publication date
- Last updated
- Relevance to current technology

### Accuracy
- Data sourcing
- Methodology
- Reproducibility
- Corroboration

### Bias
- Author perspective
- Funding sources
- Conflicts of interest

## Research Output Format

```markdown
# Research Report: [Topic]

## Executive Summary
Brief overview of findings and recommendations.

## Research Question
What we set out to discover.

## Methodology
How we conducted the research.

## Findings

### Finding 1
**Evidence**: Data supporting this finding
**Source**: Where this came from
**Confidence**: High/Medium/Low

### Finding 2
...

## Analysis
What the findings mean.

## Recommendations
What to do about it.

## Appendix
Detailed data and sources.
```

## Common Research Patterns

### "What is the best X for Y?"
1. Define Y requirements
2. Search for X options
3. Compare against requirements
4. Recommend with rationale

### "How do I implement X?"
1. Search for X documentation
2. Find implementation examples
3. Understand prerequisites
4. Provide step-by-step guide

### "Is X better than Y?"
1. Define evaluation criteria
2. Research both options
3. Compare objectively
4. Recommend based on use case

### "What are the alternatives to X?"
1. Identify X's purpose
2. Search for alternatives
3. Categorize alternatives
4. Compare features/pricing
