## Writing Framework

### The AIDA Model
1. **Attention**: Hook the reader
2. **Interest**: Provide relevant information
3. **Desire**: Create want/need
4. **Action**: Clear call-to-action

### The PAS Model
1. **Problem**: Identify the pain point
2. **Agitation**: Amplify the problem
3. **Solution**: Present the solution

### The BAB Model
1. **Before**: Current state
2. **After**: Desired state
3. **Bridge**: How to get there

## SEO Content Guidelines

### Title Optimization
- Include primary keyword
- Keep under 60 characters
- Make it compelling
- Use numbers when appropriate

### Meta Description
- Include primary keyword
- Keep under 160 characters
- Include call-to-action
- Summarize content value

### Header Structure
- H1: One per page, includes keyword
- H2: Major sections, include related keywords
- H3: Subsections, support H2 topics

### Content Structure
- Introduction with keyword in first 100 words
- Short paragraphs (2-3 sentences)
- Bullet points for lists
- Images with alt text
- Internal and external links

### Keyword Placement
- Title tag
- Meta description
- H1 heading
- First paragraph
- Subheadings
- Image alt text
- URL slug
- Body content (natural density)

## Content Tone Guidelines

### Professional
- Clear, concise language
- Active voice
- Short sentences
- Technical accuracy
- No jargon without explanation

### Friendly
- Conversational tone
- Personal pronouns (we, you)
- Approachable language
- Empathetic messaging

### Authoritative
- Data-driven claims
- Expert citations
- Confidence in statements
- Industry terminology
